# AFPs-with-ML
official repo of paper "Discovery of dual-action antifungal peptides via tiered machine learning integrating high-dimensional features"

## Core training and screening package

The [final_github_public](final_github_public/) directory contains the streamlined
training, screening, and final 21-peptide selection workflow, prepared training
inputs, reference data, and tests. See its [README](final_github_public/README.md)
for installation, verification, and reproduction instructions.

The large candidate feature matrix is not included; full screening requires
that external asset. The final selection step can be checked with the bundled
reference scores. The original scripts remain at the repository root.
